Mise en service

  1. Base de données. Dans votre projet Supabase, ouvrez SQL Editor, collez le script ci-dessous puis cliquez sur Run. Il crée les tables, les fonctions sécurisées, le compte administrateur et le projet pilote PILOT_26.
  2. Connexion. Dans les réglages du projet Supabase, copiez l’URL du projet et la clé publique (« anon » ou « publishable ») dans SUPABASE_URL et SUPABASE_KEY, au début du script de ce fichier. N’utilisez jamais la clé service_role / secret.
  3. Logo. Ajoutez le logo PILOT_26 dans le dépôt GitHub, à côté de ce fichier, sous le nom logo.png.
  4. Mise en ligne. Nommez ce fichier index.html, envoyez-le sur GitHub, puis activez Settings › Pages (branche main, dossier racine).
